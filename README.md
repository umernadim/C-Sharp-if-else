# 🧠 C# If-Else Practice Programs

This repository contains my **C# practice tasks** focused on mastering **if-else conditional statements**.
I practiced writing simple logic-based programs to understand how decisions are made in code.

## 🧩 Programs Included

### 1️⃣ Voting Eligibility Checker

Checks whether a user is eligible to vote based on their age.

```bash
Enter your age:
19
You are eligible to vote.
```

### 2️⃣ Grade Calculator

Determines a student’s grade based on their marks using if-else conditions.

```bash
Enter your marks:
78
You got A grade.
```

### 3️⃣ Even or Odd Number Checker

Identifies whether a given number is even or odd.

```bash
Enter a number:
7
7 is an odd number.
```

### 4️⃣ Largest of Two Numbers

Compares two numbers and displays which one is larger.

```bash
Enter first number:
10
Enter second number:
25
25 is the largest number.
```

## 💻 Concepts Practiced

* Conditional statements (`if`, `else if`, `else`)
* Comparison operators (`>`, `<`, `==`, `>=`, `<=`)
* Logical operators (`&&`, `||`)
* User input handling with `Console.ReadLine()`
* Type conversion using `Convert.ToInt32()`

## 🛠️ Technologies Used

* **Language:** C#
* **Platform:** .NET Console Application

## 🎯 Learning Objective

The main goal of this practice was to strengthen the understanding of:

* Decision-making in programming
* Real-world logic implementation
* Writing clean and efficient conditional code
